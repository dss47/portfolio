# Saad El-Assali — Portfolio

Personal portfolio website for **Saad El-Assali**, a software engineering student interested in web development, Linux systems, native applications, automation, and software engineering.

🌐 **Live website:** https://www.selassali.tech

## Tech Stack

* Next.js
* React
* TypeScript
* Tailwind CSS

## Featured Projects

* **IT Mall** — AI-powered voice commerce and ERP automation platform.
* **RPS It!** — Retro 2D Rock-Paper-Scissors game built with Godot and GDScript.
* **GTK4 Aquarium** — Native Linux desktop application built with C and GTK4.
* **Penguins** — AI tools discovery platform.
* **CollabSpace** — Collaborative workspace platform.
* **TaskFlow** — Agile task management board.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/dss47/portfolio.git
cd portfolio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Then open `http://localhost:3000`.
